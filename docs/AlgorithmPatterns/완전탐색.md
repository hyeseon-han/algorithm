### DFS 깊이 우선 탐색

DFS와 다르게 복구 할 필요 없음

DFS 에서는 한 경로를 끝까지 파고들기 때문에 나중에 더 짧은 경로가 나올 수도 있어서 복구를 해야하지만 BFS인 경우에는 복구 할 필요 없음.

```js
visited[x][y] = true;
// ...
visited[x][y] = false; // 백트래킹 시 복구
```

왜냐하면 가까운 거리 → 먼 거리 순으로 가기 때문에 한번 방문 했으면 최단거리 계산 끝났다고 판단
